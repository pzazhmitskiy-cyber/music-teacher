# Уроки музыки

Сервис для учителя музыки: ученики с ценами, постоянные и разовые уроки, домашние задания, годовой план, оплаты и ссылка для родителей.

## Что умеет

- **Расписание по неделям.** Постоянные уроки («каждый вторник в 16:00») появляются сами. Урок можно отметить проведённым, отменить, отметить как оплачиваемый пропуск или перенести. Отдельно добавляются разовые уроки.
- **Карточка ученика.** Имя и фамилия, дата рождения, документы, гражданство, адрес, инструмент, общая информация, школа или частный, цена, длительность, годовой план, заметки, история уроков с домашкой.
- **Родители.** У каждого ученика может быть несколько родителей с телефоном и почтой.
- **Оплаты и баланс.** Баланс равен оплатам минус стоимость проведённых уроков и пропусков. При смене цены пересчитываются будущие уроки.
- **Итоги месяца.** Суммы отдельно по частным ученикам и по школе, плюс полученные оплаты.
- **Ссылка для родителей** `/p/<секрет>`. На странице видны расписание, домашние задания и план на год. Цены и заметки не видны. Ссылку можно сменить.

Дальше по плану: Telegram-бот (уроки на сегодня, напоминания, отметка «проведён») и открытие сайта внутри Telegram как Mini App.

## Запуск

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. В Supabase откройте **SQL Editor**, вставьте содержимое `supabase/schema.sql` и нажмите Run. Файл `schema.sql` всегда описывает схему целиком. Если база создана раньше, выполните по порядку новые файлы из `supabase/migrations/`.
3. В **Authentication → Sign In / Providers → Email** можно выключить «Confirm email», чтобы входить без письма.
4. Скопируйте `.env.example` в `.env.local` и заполните его значениями из **Project Settings → API**.
5. Запустите:
   ```bash
   npm install
   npm run dev
   ```
   Откройте http://localhost:3000, нажмите «Создать аккаунт» и войдите.
6. Когда аккаунт учителя создан, выключите регистрацию новых пользователей: **Authentication → Sign In / Providers → Allow new users to sign up**. Чужие данные посторонние не увидят и так, но лишние аккаунты ни к чему.

## Публикация

Самый простой путь: импортировать репозиторий на [vercel.com](https://vercel.com) и задать там те же три переменные окружения. Если Vercel или Supabase работают из России с перебоями, приложение можно запустить на любом VPS через `npm run build && npm start`.

## Устройство

- Next.js 15 (App Router, серверные компоненты и server actions), без клиентского JS для данных.
- Supabase: Postgres и вход по почте с паролем. Доступ ограничен политиками RLS: каждый видит только свои строки.
- Страница для родителей вызывает SQL-функцию `parent_view(token)`, которая отдаёт только разрешённые поля.
- Постоянные уроки хранятся в `recurring_slots`. Конкретные уроки создаются в `lessons`, когда открывается неделя или карточка ученика. Уникальность по `(slot_id, slot_date)` не даёт создать урок дважды, а перенос меняет только `lesson_date`.
